CLIENT LOGOS
Drop each client's logo here (PNG, JPG, WebP or SVG; square-ish, ~200x200 px or larger).
Name the file after the client using lowercase letters and hyphens, e.g.  status-fashion.png
Outlets with the same name share one logo file. See clients-logo-checklist.txt in the project folder
(rewritten on every build) for the exact file name each client needs.
Only use logos you have permission to show. Without a logo, a neat initials tile is shown.
